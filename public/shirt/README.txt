The shirt size chart shown inside the "Shirt size" question on the
registration screen.

  shirt-size.<ext>

<ext> can be jpg, png, jpeg or webp, and an underscore works as well as a
hyphen — shirt_size.png is found just as shirt-size.jpg is. The page tries
each spelling in turn, so the file can go in exactly as it came off the
designer or the scanner.

The chart is shown whole, never cropped, with a "Full size" link so the
measurements can actually be read on a phone. A landscape image around
1200x800 works well. Keep it under about 300 KB.

With no file here the tile shows an "Image coming soon" placeholder, so the
question still works — runners simply pick from the size chips as before.
